Bobine

Studio vidéo IA, sur ton ordinateur

Une idée, une vidéo prête à publier.

Écris une phrase ou dépose une image. Bobine écrit le script, crée les visuels, la voix française, les sous-titres et monte le tout en vertical.

Mode démo : aucune clé OpenAI détectée. Les vidéos utilisent un script gabarit et des visuels abstraits. Ajoute tes clés dans studio_video/.env.
